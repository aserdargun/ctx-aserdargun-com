# CTX Context & Knowledge Engineering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, validate, and publish the approved bilingual CTX research instrument as a public GitHub repository and an Azure Static Web Apps Free site.

**Architecture:** A React/Vite static SPA imports Zod-validated bilingual JSON at build time. Focused route, query-state, research-data, and view modules keep the eleven-stage pipeline, technique atlas, pattern explorer, evidence ledger, and methodology independently testable. A checkout-scoped lifecycle and one prebuilt-artifact deployment workflow provide reproducible local and production releases.

**Tech Stack:** Node.js 22, npm, React 19, React Router, Vite 8, TypeScript 6, Zod, Vitest, Testing Library, ESLint, Playwright, axe-core, Azure Static Web Apps.

**Spec:** `docs/superpowers/specs/2026-09-02-ctx-context-knowledge-engineering-design.md`

## Global Constraints

- Product code and repository name are fixed as `ctx` and `ctx-aserdargun-com`.
- Public strings must have non-empty `en` and `tr` values in the same logical record.
- The pipeline contains exactly eleven ordered stages from `source` through `memory`.
- Claims are labeled `evidence`, `synthesis`, or `watch-signal`; unknown values are absent rather than guessed.
- No unsourced numeric benchmarks, vendor rankings, user uploads, accounts, analytics, database, server runtime, Azure Functions, or Vercel files.
- The accepted desktop and mobile concept images are the visual source of truth; generated fake mobile metrics are explicitly excluded.
- Interactive controls are at least 44 by 44 CSS pixels on mobile, keyboard operable, focus visible, and usable with reduced motion.
- The static artifact is `dist/`; local preview binds only to `127.0.0.1:4175`.
- Azure target is `aserdargun subscription 2`, `rg-ctx-aserdargun-com`, `swa-ctx-aserdargun-com`, West Europe, Free.
- Custom-domain DNS and root-portfolio integration are outside this implementation plan's mutation scope.
